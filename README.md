# WildLife NotesSV

Aplicación sencilla para gestionar tareas, creada con **Vite, TypeScript, HTML y CSS**, sin frameworks.

## Características

- Crear tareas.
- Editar tareas.
- Eliminar tareas con confirmación.
- Marcar tareas como completadas o pendientes.
- Filtrar por estado y prioridad.
- Buscar tareas por título.
- Guardar las tareas en `localStorage`.
- Diseño adaptable a dispositivos móviles.

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/garodriguezsv/wildlife-notes.git
```

2. Entra en la carpeta:

```bash
cd wildlife-notes
```

3. Instala las dependencias:

```bash
pnpm install
```

4. Inicia el proyecto:

```bash
pnpm dev
```

5. Abre en el navegador la dirección que muestre Vite.

## Uso

1. Presiona **Nueva tarea**.
2. Completa el título, descripción, categoría y prioridad.
3. Guarda la tarea.
4. Usa los botones de cada tarea para editarla, completarla o eliminarla.
5. Utiliza los filtros y el buscador para encontrar tareas.

## Tecnologías

- TypeScript
- Vite
- HTML5
- CSS3
- pnpm
- localStorage
